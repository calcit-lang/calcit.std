# Release 0.2.28 / 发布 0.2.28

## 中文

- 发布 `read-file-by-line!` 的真实逐行流式实现，峰值内存由 O(file size) 降为 O(reader buffer + longest line)。
- callback schema 收紧为 `Fn(String) -> Unit`，并在 Calcit 0.13.68 的 blocking Unit/EDN transport 修复上完成公开 API 回归。
- 包含 CRLF/LF、callback 失败早停、100 万行压力测试与 Rust 1.98 strict Clippy 兼容。

## English

- Release true line streaming for `read-file-by-line!`, reducing peak memory from O(file size) to O(reader buffer + longest line).
- Tighten the callback schema to `Fn(String) -> Unit` and validate the public API on Calcit 0.13.68 with its blocking Unit/EDN transport fix.
- Include CRLF/LF semantics, callback-failure early stop, a one-million-line stress test, and Rust 1.98 strict Clippy compatibility.
