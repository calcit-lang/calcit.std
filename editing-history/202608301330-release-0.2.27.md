# Release 0.2.27 / 发布 0.2.27

## 中文

- 发布 `calcit.std` 0.2.27，要求 Calcit 0.13.64。
- 保持 `calcit_native_ffi 0.1.3`、C-safe buffer/async/blocking ABI、typed async task capabilities 与类型质量 baseline 不变。
- 发布前继续覆盖 timer、interval、process stream、cancellation、Ctrl+C 与可执行文档验证。

## English

- Release `calcit.std` 0.2.27 with Calcit 0.13.64 required.
- Keep `calcit_native_ffi 0.1.3`, the C-safe buffer/async/blocking ABI, typed async task capabilities, and the type-quality baseline unchanged.
- Continue covering timers, intervals, process streaming, cancellation, Ctrl+C, and runnable docs before release.
