# Upgrade Calcit to 0.13.77 / 升级 Calcit 到 0.13.77

## 中文

- 将 `deps.cirru` 中声明的 Calcit 工具链版本从 0.13.72 升级到 0.13.77。
- 为 `stream-process` 测试入口增加显式 Unit 收尾，保留异步任务启动行为并满足 0.13.77 的严格返回类型检查。
- 在 CI 中显式请求 `calcit,caps`，避免 `setup-calcit@v1.3.0` 的 legacy `cr` 默认别名请求不存在的 0.13.77 release asset。
- 使用 0.13.77 CLI 检查 canonical Snapshot、类型质量门禁、native FFI 与真实运行回归。
- 保持 calcit.std 0.2.30 的模块版本、generated bindgen 资产和 native ABI 契约不变。

## English

- Upgrade the declared Calcit toolchain in `deps.cirru` from 0.13.72 to 0.13.77.
- Add an explicit Unit tail to the `stream-process` test entry, preserving async task startup while satisfying Calcit 0.13.77's strict return-type check.
- Explicitly request `calcit,caps` in CI so `setup-calcit@v1.3.0` does not use its legacy `cr` default alias and request a nonexistent 0.13.77 release asset.
- Validate the canonical Snapshot, type-quality gate, native FFI, and real runtime regression with the 0.13.77 CLI.
- Keep the calcit.std 0.2.30 module version, generated bindgen assets, and native ABI contract unchanged.
