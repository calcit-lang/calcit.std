# Rust 1.98 Clippy compatibility / Rust 1.98 Clippy 兼容

## 中文

- GitHub Actions 的 Rust 1.98 新增 `chunks_exact_to_as_chunks` lint，本地固定工具链未提前报告。
- 将 100 万行测试生成器的固定二元切片改为 `as_chunks_mut::<2>()`，不改变测试数据或生产实现。
- 使用更新的 nightly 工具链额外执行 strict Clippy，覆盖 CI 新 lint。

## English

- GitHub Actions on Rust 1.98 enabled the new `chunks_exact_to_as_chunks` lint, which the pinned local toolchain did not report.
- Use `as_chunks_mut::<2>()` for the fixed two-byte stress-test generator without changing test data or production behavior.
- Run strict Clippy with a newer nightly toolchain to cover the CI lint set.
