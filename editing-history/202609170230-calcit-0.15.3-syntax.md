# Calcit 0.15.3 语法迁移 / Calcit 0.15.3 syntax migration

## 中文

- 将项目与 CI 固定到 Calcit 0.15.3。
- 用具名 `Date0` 构造器替换旧 `%{}` Struct 构造语法。
- 移除测试中的冗余 `do`，并让异步测试辅助函数显式返回 `Unit`。

## English

- Pin the project and CI to Calcit 0.15.3.
- Replace legacy `%{}` Struct construction with the named `Date0` constructor.
- Remove a redundant test `do` and make asynchronous test helpers return `Unit` explicitly.

## 验证 / Verification

- `calcit fix --preset surface-latest-v2 --format edn`
- `calcit --check-only --strict-types`
- `calcit analyze quality --format json`
- `cargo fmt --check`
- `cargo test`
- `cargo clippy --all-targets -- -D warnings`
