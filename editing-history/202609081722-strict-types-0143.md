# Calcit 0.14.3 strict types / Calcit 0.14.3 严格类型

## Summary / 摘要

- Pin Calcit 0.14.3 and replace the compatibility baseline with the zero-debt strict quality gate. / 固定 Calcit 0.14.3，并以零债务严格质量门禁替换兼容基线。
- Close date, filesystem, process, and random contracts with concrete `Number`, `Tag`, collection, callback, and `Option` types. / 使用具体的 `Number`、`Tag`、集合、callback 与 `Option` 类型闭合 date、filesystem、process 和 random 契约。
- Remove legacy Date method-bag and JSON Dynamic facades; document canonical named date functions and Calcit core JSON APIs. / 移除旧 Date method-bag 与 JSON Dynamic facade，改为文档化规范命名 date 函数和 Calcit core JSON API。
- Update native random decoding, runnable examples, and async smoke fixtures for canonical `Option` values and strict dispatch. / 更新 native random 解码、可运行 examples 与 async smoke fixture，使用规范 `Option` 值与严格 dispatch。
