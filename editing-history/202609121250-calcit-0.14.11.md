# Calcit 0.14.11 / Calcit 0.14.11

## 中文

- 将项目要求的 Calcit 从 0.14.7 升级到 0.14.11，模块版本保持 0.2.31 不变，并保持 `calcit.std` 公共 API 与 C-safe dylib 契约不变。
- 结构化的 `Fn` schema 取代整份 `Dynamic`；`--check-only`、质量门禁与 dynamic-method 门禁通过。
- CI 版本断言更新为 0.14.11，并固定 `actions/checkout`、`calcit-lang/setup-calcit` 到不可变 commit。

## English

- Upgrade the required Calcit from 0.14.7 to 0.14.11, keeping the module version at 0.2.31 while preserving the `calcit.std` public API and C-safe dylib contract.
- Structured `Fn` schemas replace whole-`Dynamic`; `--check-only`, the quality gate, and the dynamic-method gate pass.
- CI version assertion updated to 0.14.11; pin `actions/checkout` and `calcit-lang/setup-calcit` to immutable commits.
