# Calcit 0.13.64 upgrade / 升级记录

## 中文

- 将标准模块要求的 Calcit 版本从 0.13.60 升级到 0.13.64。
- 保持 C-safe buffer/async/blocking ABI、共享 `calcit_native_ffi 0.1.3` 与既有类型 baseline 不变。
- 通过 runnable docs、异步 examples、跨 toolchain FFI trace 和真实 std 模块入口验证。

## English

- Upgrade the standard module's required Calcit version from 0.13.60 to 0.13.64.
- Keep the C-safe buffer/async/blocking ABI, shared `calcit_native_ffi 0.1.3`, and existing type baseline unchanged.
- Verify with runnable docs, async examples, a cross-toolchain FFI trace, and the real std module entry.
