# Release 0.2.31 / 发布 0.2.31

## 中文

- 发布包含 Calcit 0.13.77 升级与 Date trait 修复的 `calcit.std` 0.2.31。
- 同步 `Cargo.toml`、`Cargo.lock` 与 `deps.cirru` 的版本元数据。
- 保持公开 API、native FFI 协议、generated adapter 与运行时行为不变。

## English

- Release `calcit.std` 0.2.31 with the Calcit 0.13.77 upgrade and Date trait fix.
- Keep the version metadata in `Cargo.toml`, `Cargo.lock`, and `deps.cirru` synchronized.
- Preserve the public API, native FFI protocol, generated adapters, and runtime behavior.
