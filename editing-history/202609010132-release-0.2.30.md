# 发布 0.2.30 / Release 0.2.30

## 中文

- 发布首个由 `calcit-bindgen 0.1.0` 管理真实 MD5 native FFI adapter 的
  `calcit.std` 版本。
- 同步 `Cargo.toml`、`deps.cirru`、`Cargo.lock` 与 generated Interface IR 的
  package version，避免发布元数据和 stale-binding gate 不一致。
- 使用 Calcit 0.13.72 重新导出 Interface IR，并以固定版本 generator 重建
  Rust adapter 与 manifest。

## English

- Release the first `calcit.std` version whose real MD5 native FFI adapter is
  managed by `calcit-bindgen 0.1.0`.
- Keep `Cargo.toml`, `deps.cirru`, `Cargo.lock`, and the generated Interface IR
  package version aligned so release metadata and the stale-binding gate agree.
- Re-export Interface IR with Calcit 0.13.72 and rebuild the Rust adapter and
  manifest with the pinned generator release.
