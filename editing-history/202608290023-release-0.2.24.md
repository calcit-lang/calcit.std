# 发布 0.2.24 / Release 0.2.24

## 中文

- 发布基于稳定 `calcit_native_ffi 0.1.3` 的 process、timer 与 Ctrl+C 可取消背压。
- 持续 `QUEUE_FULL` backlog 中 cancel 可打断普通事件重试，terminal 仍可靠发布。

## English

- Release cancellable process, timer, and Ctrl+C backpressure based on stable `calcit_native_ffi 0.1.3`.
- Allow cancellation to interrupt ordinary event retries during persistent `QUEUE_FULL` backlog while preserving reliable terminal publication.
